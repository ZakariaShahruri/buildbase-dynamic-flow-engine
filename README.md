# BuildBase Dynamic Flow Engine

A flexible system designed to automate and track business processes (like onboarding and absence approvals) for BuildBase (Strouwi BV). 

This project features an easily extendable configurable process system, flow visualization, state tracking, and real-time WebSockets notifications.

## 🚀 Tech Stack
* **Frontend:** Vue.js, TypeScript, Tailwind CSS
* **Backend:** Java, Spring Boot, WebSockets
* **Database:** MongoDB
* **Deployment:** OKD Environment
